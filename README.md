## Пояснения
1. Мне было удобнее пользоваться докером, поэтому я сделал просто два контейнера с api и postgres
2. Я не совсем понял, как предполагается отдавать по http результаты запросов, поэтому я их возвращаю в обычных json, модели pydentic лежат в models.py
2. В задании было указано считать количество комментариев, но в схеме таблицы под комментарии не было, поэтому я решил что это проверка на дурачка и создал ее, все схемы лежат в скрипте питона
3. Таблицы я создавал и делал запросы к ним через sqlalchemy, потому что я фанат ORM, и так в целом намного проще и понятнее
4. Скрипты для генерации тестовых данных на SQL лежат в директории sql, но использовать их нужно только после первого запуска контейнеров, так как таблицы создаются автоматически sqlalchemy
5. Пример .env тоже лежит в корне, без него работать не будет
6. Так как я пользовался poetry для отслеживания зависимостей, то в проекте есть pyproject.toml, и requirements.txt сгенерирован самим poetry, поэтому он нечитаемый
